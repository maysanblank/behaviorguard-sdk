# assets/

Images used by the top-level `README.md`.

| File | What it shows |
|---|---|
| `banner.svg` | Header banner at the top of the README |
| `arunika-demo.gif` | The owner and an attacker on the same account in Arunika, the demo bank (a GIF of `arunika-demo.mp4`) |
| `arunika-demo.mp4` | The same recording in full quality |
| `demo.gif` | Installing BehaviorGuard into a plain store (in VS Code), then the owner and a second browser with the stolen password |

Both are recordings of the real demos; nothing in them is mocked. The Arunika recording is two
people at the keyboard (the owner, then someone else), edited for length. `demo.gif` is driven
by a script with human-like mouse and keyboard input. To see the same thing live, run
`python demo/arunika/server.py` or follow
[demo/shop-checkout/README.md](../demo/shop-checkout/README.md).
